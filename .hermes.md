# ai-workflow-benchmark

## Rules

- This is a public repository. Keep issues, pull requests, documentation,
  examples, and code free of private infrastructure details, credentials, and
  internal network information.
- Use feature branches; do not push directly to the default branch.
- Keep deployment and execution guidance portable and infrastructure-neutral.

## Architecture decisions

Read [`docs/adr/`](docs/adr/README.md) before proposing changes to benchmark
methodology, evaluation criteria, run isolation, or public-artifact boundaries.

## Delivery guidance

- Deliver the smallest working, verifiable increment that meets the current request.
- Do not add speculative features, abstractions, or configuration for possible future needs.
- Preserve existing repository instructions and validate changed behavior with the narrowest relevant check.
